# Baron Analytics v1.10.9

דשבורד ניתוח מכירות מתקדם לחברת ברון

## נתונים
- 1,075 חנויות
- 134 מוצרים
- 24 חודשים (ינואר 2024 - דצמבר 2025)
- 144 ערים
- 26 נהגים

## תכונות עיקריות
- בורר תקופות (H1/H2, Q4, שנתי)
- נתונים מורחבים (ברוטו, נטו, חזרות, משלוחים)
- לוח חגים
- השוואות מתקדמות (חנויות + מוצרים)
- ייצוא PDF

## חדש בגרסה 1.10.9

### דף מוצרים (ProductsList)
- **2 טבלאות**: מדדים + נתונים (עם בורר תקופה)
- **צ'קבוקסים** לבחירת מוצרים להשוואה
- **שורת סיכום** בכותרת עם ממוצעים/סכומים
- **כפתור "השווה"** שנפתח עם מוצרים שנבחרו
- ייצוא Excel לכל טבלה

### פירוט מוצר (ProductDetail) - חנויות שמוכרות
- **2 טבלאות**: מדדים + נתונים (עם בורר תקופה)
- **צ'קבוקסים** לבחירת חנויות להשוואה
- **שורת סיכום** בכותרת
- **כפתור "השווה"** לפתיחת מודל השוואה
- ייצוא Excel/PDF לכל טבלה

### מודלי השוואה
- 2 טבלאות: מדדים + נתונים
- בורר תקופה לטבלת נתונים
- חיפוש להוספת פריטים נוספים
- שורות סיכום
- ייצוא PDF + Excel
